# feat(domain): replace Damagable with expressive capabilities

## Summary
Replaced the generic `Damagable` trait with three expressive, game-domain-specific capabilities:
- `CanBeAttacked`
- `ImmuneToDamage`
- `HasAttackPower`

These improvements enhance code clarity, align with real card game mechanics, and support composable gameplay logic.

## Changes
- Created new marker traits in `crates/domain/src/traits/`
- Applied appropriate traits to `Card`, `Player`, and `Creature`
- Removed obsolete `damagable.rs` and its exports
- Added missing module re-exports and import fixes
- Resolved all build and test failures through targeted edits

## Impact
- Improved maintainability and expressiveness of core domain model
- Enabled more precise targeting and combat rules in TUI gameplay
- Eliminated ambiguous `Damagable` semantics that didn't reflect actual game behavior

## Verification
All builds and tests pass successfully. No regressions observed.
